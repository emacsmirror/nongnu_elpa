* MIT Scheme and Geiser talk to each other

This package provides support for using [[https://www.gnu.org/software/mit-scheme/][MIT/GNU Scheme]] in Emacs with
[[http://geiser.nongnu.org][Geiser]].

The easiest way to install ~geiser-mit~ is from MELPA, using ~M-x
package-install RET geiser-mit~.

* Contributing
*** Generative AI (LLMs)

  Use of generative AI (LLMs, diffusion models and similar technology) is not
  acceptable for contributions to or interactions with the Geiser project.

  This includes words, images and code, as well as bug reports, commit
  messages, email (mailing list or private) and IRC messages.
