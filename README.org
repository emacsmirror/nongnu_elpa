* Codex IDE integration for GNU Emacs

** About
+ [[https://github.com/openai/codex][codex]] native integration for emacs, utilizing [[https://codeberg.org/akib/emacs-eat][eat]]
  + Run Codex in a project-scoped eat buffer.
  + Resume, switch, and manage multiple live Codex sessions from Emacs.

** Terminal scrolling
+ =C-c C-e= enters Eat's read-only Emacs mode for ordinary scrolling,
  movement, search, and selection.
+ =C-c C-j= restores terminal input and jumps to the live Codex frame.

** Installation
+ Using =:vc=
#+begin_src emacs-lisp
(use-package codex-ide
  :vc (:url "https://git.thanosapollo.org/emacs-codex-ide"
       :lisp-dir "lisp"
       :rev :newest))
#+end_src

+ Using =straight.el=
#+begin_src emacs-lisp
(straight-use-package
 '(codex-ide :type git
             :host nil
             :repo "https://git.thanosapollo.org/emacs-codex-ide"
             :files ("lisp/*.el")))
#+end_src
