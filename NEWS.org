#+title: emacs-codex-ide NEWS

* Unreleased

- Resume saved conversations in new live sessions, preserving existing sessions.
  Keep the picker newest first, annotate IDs with date and directory, cache
  rollout metadata, and resume global fallback choices in their recorded cwd.
- Keep failed terminal output with an exit notice. Customize
  =codex-ide-kill-buffer-on-exit= to retain all buffers or close all exits.
- Confirm interactive session stops and continue after optional context startup
  failures. Show the session label and backend in the mode line.
- Use the configured display policy for session switching and panels, scope
  window lookup to the selected frame, and restore splits when hiding.
- Send literal Ctrl+J for newlines, retain minibuffer prompt history, and display
  source attachments without selecting the session, using project-relative paths.
- Cache CLI availability, failures and version output by executable path.
- Make =codex-ide-list-sessions= a native tabulated session list with
  switching, confirmed kill, labels, refresh, and popup help.  Its former
  completion behavior is now =codex-ide-switch-session=.
- Rename project completion to =codex-ide-switch-project-session= and
  cycling to =codex-ide-cycle-session=.  Keep the former
  =codex-ide-list-project-sessions= and =codex-ide-toggle= as obsolete aliases.
- Keep popup =q= for exit/back; move session kill to =k= and MCP stop to =K=.
  Organize the menu by goal in two columns, add Context actions, use =l=/=L=
  for project/all session completion, and dim unavailable actions.
- Show current backend, approval, and sandbox overrides in configuration.
  Save only nondefault options, remove saved overrides restored to defaults,
  and allow a bare CLI executable name.

* Version 0.1.4 (unreleased)

- Select native neo-term automatically in Neomacs, preserving explicit
  customization and existing session backends. Eat is now a lazy optional
  dependency and remains the GNU Emacs default.
- Register Neomacs' existing native MCP tools via its stdio relay and exact
  active socket, without a GNU MCP fallback or persistent config writes.
- Refuse inherited native HTTP transport conflicts before launch, preserve
  native enablement/tool policy, and disable inherited GNU MCP only for the
  native session. Explicit persistent setup warns about policy replacement.
- Preserve explicit GNU bridge enablement overrides in native sessions and
  refuse uninspected profile/config/cwd or remote extra CLI arguments before
  automatic native MCP launch.
- Compile all optional adapters without Eat, diagnose missing Eat at selection,
  and preserve errors loading installed backends.
- Track native PTY resources and settlement hooks for session recovery,
  literal prompt input and owner-scoped cleanup.
- Add an inexpensive installed-Neomacs source/bytecode verification target.

- Label and rename live sessions, and restore project session panels per tab.
- Register custom Emacs MCP tools.
- Review editable proposals asynchronously with Ediff, including submission
  and retrieval over MCP.
- Attach source to a terminal draft without submitting it.
- Paste prompts literally and reject stale input owners across interactive
  waits, preserving sibling sessions and backend ownership.
- Preserve vterm sessions when a major-mode change is rejected, clean up
  failed startup and terminal exits, and report native module load errors.

* Version 0.1.3 (2026-09-04)

- Validate supplied MCP argument types before invoking tools, and require
  an explicit buffer or path for structured edits.
- Support stateless MCP 2026-07-28 while preserving legacy initialization.
- Roll back structured MCP edits when editing or indentation fails.
- Avoid leaking output buffers for empty MCP execution requests.
- Read complete rollout metadata up to one MiB and report oversized lines.
- Apply the resume limit to matching sessions, so unrelated activity does
  not hide older project sessions; collect timestamps once before sorting.

* Version 0.1.2 (2026-09-02)

** Sessions

- Use concise project-based buffer names and add stable root identities only
  when equal basenames collide.
- Preserve session ownership across recovery, replacement, and cleanup paths.

** MCP and permissions

- Restore the full local MCP control tool set and add YOLO mode.
- Harden MCP and session lifecycle cleanup.

** Menu

- Present boolean options as popup switches.

* Version 0.1.1 (2026-08-13)

** Terminal backends

- Added optional vterm support.  Eat remains the default and required
  terminal backend.
- Kept terminal process ownership and session cleanup consistent across
  backends.

** Packaging

- Raised the minimum supported Emacs version to 29.1.
- Added package autoload generation and validation to the Nix package.
- Added package-lint to the project release gates.

** MCP and context

- Restricted the local MCP server to loopback bind addresses.
- Fixed MCP endpoint URLs for the IPv6 loopback address.
- Documented compatibility with current and legacy Codex context IPC paths.
